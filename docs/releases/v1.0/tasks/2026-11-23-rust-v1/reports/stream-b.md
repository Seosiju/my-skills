## Differences from v0.4.1

- Deliberate. The effective `install_mode` defaults to `link` and accepts only `link` or `copy`. A higher-priority mode takes precedence before validation.
- Deliberate. Explicit skill selection follows sorted manifest order. The manifest also retains the optional `group` field.
- Deliberate. Tilde expansion uses the current home from `paths::home_dir()`. Named-user forms such as `~other` stay literal. List settings require TOML arrays and discard non-string elements. Python also accepted table keys as list entries. Schema strings use trimmed signed 64-bit integer parsing, so Python's additional spellings, including digit separators, are outside the Rust parser's range.
- Deliberate. State implements the Rust record types and reports malformed payloads with `Error::State`. It supports `link_kind` and `fallback_reason` and writes LF line endings on all platforms.
- Deliberate. A save reserves the temporary file exclusively and syncs it before renaming. A pre-existing `.tmp` produces an I/O error and leaves the saved state intact.
